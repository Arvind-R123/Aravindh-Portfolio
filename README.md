# Aravindh R Portfolio

Plain HTML5, CSS3 and vanilla JavaScript. No build step or npm dependencies.

Edit content in index.html. Replace assets/Aravindh_R_Resume.pdf and the image placeholders before launch.

Run locally: python -m http.server 8000

Deploy: push to GitHub, import in Vercel, choose Other, leave build command empty, and set output directory to `.`. CLI: npm i -g vercel; vercel; vercel --prod.
